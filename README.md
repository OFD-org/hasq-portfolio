# h4sq — Ivan Avhustynovych

Personal portfolio for motion designer Ivan Avhustynovych. A responsive static website featuring video work, performance creatives, experience, and contact details.

## Run locally

Requires Node.js 22 or later.

```sh
npm run dev
```

Open [localhost:8000](http://127.0.0.1:8000). The local server supports video seeking. No build step or dependency installation is needed to view the checked-in website.

## Project structure

```text
assets/works/media/       Optimized films, previews, and images used by the gallery
fonts/                   Local fonts
js/
  components/            Gallery and full-size media viewer
  data/                  Media manifest and display titles
  works.js               Gallery entry point
scripts/                 Local server, media preparation, and validation
index.html               Page content and navigation
cv.css                   Page layout and visual styles
works.css                Gallery and viewer styles
motion.js                Page animation and scrolling
favicon.svg              Browser icon
ivan-cv.pdf              Downloadable CV
```

## Editing content

- Update profile text, experience, and contact links in `index.html`.
- Edit project display names in `js/data/work-titles.js`.
- Edit gallery media and categories in `js/data/works.js`. This file is regenerated by the media script.
- Replace `ivan-cv.pdf` when updating the downloadable CV.

The gallery groups work into **2D & 3D motion**, **Performance creatives**, and **SaaS / Brand**. Videos preview on hover or tap and open in a full-size player with audio controls. Static creatives use an image grid. Keyboard navigation and reduced-motion preferences are supported.

## Preparing new media

Original exports are kept locally and excluded from Git. The website only needs the optimized files in `assets/works/media/`; the original folders are not missing deployment dependencies.

The preparation script expects this local source structure:

```text
2D & 3D_motion/
  *.mp4
  motion_edits (just-for-fun)/
performance_creatives/
  creatives/
    videos/
    static/
  UI_animations(screen casts, outros)/
SaaS _ Brand content (in progress)/
```

To generate media from those originals:

```sh
npm ci
npm run media:prepare
npm run check
```

The script preserves the originals and generates JPEG images, muted previews of up to eight seconds, and H.264/AAC full-length MP4s with a maximum dimension of 1280 pixels. Full films are capped at 30 fps with a constrained bitrate for web delivery. Display names in `work-titles.js` survive regeneration.

Existing generated files are reused. When replacing a source under the same filename, remove its corresponding generated files before running preparation again. Keep original exports backed up separately.

## Validation

```sh
npm run check
```

Checks JavaScript syntax, media references, unique project IDs, image dimensions, and preview file headers. Before publishing, check video playback, category filters, contact links, and the CV download in a browser.

## Deployment

Serve the repository root on a static host. For GitHub Pages, select the `main` branch and root folder in the repository's Pages settings. Include `assets`, `fonts`, `js`, the page files, and the downloadable CV. No server runtime is required in production.

Commit the optimized media alongside the code. `node_modules`, original media folders, ZIP archives, and local QA screenshots are excluded through `.gitignore`.
